- `client/src/types/licensee.ts` — remove 7 fields from client `ILicensee`
- `client/src/types/user.ts` — `IUser.licensee` may Pick from ILicensee; verify and remove picked plugin fields
- `client/src/services/onboarding.ts` — `OnboardingFields` type likely includes plugin fields; remove them
